# python-for-school
# Python для школьника

Проект для изучения Python: задачи, примеры, мини-проекты и тесты.

## Структура
- `week1/` — основы, ввод/вывод, математика
- `week2/` — условия и циклы
- `week3/` — списки, словари, функции
- `week4/` — файлы и обработка ошибок
- `projects/` — мини-проекты
- `tests/` — тесты (pytest)

## Как запустить
1. Установить Python 3.11+
2. Создать виртуальное окружение: `python -m venv venv`
3. Активировать: Windows `venv\Scripts\activate`, Linux/macOS `source venv/bin/activate`
4. Установить зависимости: `pip install pytest`
5. Запустить скрипт: `python week1/hello.py`

## Тесты
Запустить тесты: `pytest`
